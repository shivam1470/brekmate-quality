# Local execution
Prerequisite: Node.js 22+ (no external npm packages needed for current checks).
```
npm run generate
npm run test:catalogue
npm run test:product
npm run readiness
```
First two should pass. Product checks fail explicitly without actual adapters. Connect the actual product before claiming feature results. Set BREKMATE_TEST_ADAPTER for the 432 pricing examples and BREKMATE_BASKET_ADAPTER for 36,864 basket combinations. Use SHARD_INDEX / SHARD_TOTAL for basket contract selection. Full UI and provider commands are not available until drivers exist.

Google Drive is a file copy, not a CI runner or automatic two-way sync. Download the workspace ZIP or mirror folder for Mac/Codex work. Do not run source from a Drive-sync folder and a Git clone simultaneously without defining which copy is authoritative. Edits here can be written back to these Drive IDs in later requests; no background maintenance runs between conversations.
